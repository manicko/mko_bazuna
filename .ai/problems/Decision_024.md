Кнопки раскрытия подкатегорий в выпадающем меню "Все категории" слишком маленькие (32×32px) и используют правостремленный уголок ▶, который не интуитивен для раскрытия в месте.

Исследование (/ai/research/25_main-menu-navigation_research.md) показало:
- NN/g: правостремленный уголок ▶ НЕ подходит для аккордеонов (p<0.05, empirically tested).
- Рекомендуется downward-caret ▼ с поворотом 180° при раскрытии.
- Plus/minus (+) допустим, но медленнее распознаётся и путает с "add/remove".
- Размер кнопки: 44×44px (стандарт проекта ui-patterns.md, WCAG 2.5.5 AA, Apple HIG).

Решения:
1. Заменить правостремленный уголок ▶ на downward caret ▼ с CSS-поворотом 180° при aria-expanded="true".
2. Увеличить область клика до 44×44px (p-3 + min-w-11 min-h-11), оставить иконку 16px.
3. Добавить aria-controls для связи кнопки с контейнером подменю.
4. Approach A (минимальный): только иконка + размер + aria-controls + поворот. Никаких JS-поведенческих изменений.
5. Approach B (следующий тикет): объединить label + icon в одну кнопку раскрытия (убрать split-action), добавить role="tree"/"treeitem"/"group" + клавиатурная навигация.
6. Одинаково для desktop dropdown, mobile off-canvas, и lazy-loaded mega_submenu.html.
